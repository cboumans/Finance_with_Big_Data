# Finance with Big Data (20598) – Group 4

```
Finance_with_Big_Data/
```

**Project:** start with `project/Replication_Group4.ipynb`. `project/README.md` explains the setup, the
data and the pipeline; the slides are in `project/slides/`.

**Labs:** run each notebook from its own folder; large raw data (Lab 3 texts, Lab 5 bank data) are
git-ignored and come from the course page.
